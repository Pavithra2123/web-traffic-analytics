# Web Traffic Analytics

## Project Overview
Web Traffic Analytics is a data analysis project using Python. This project analyzes website traffic data to understand visitor behaviour, page views, traffic sources, device usage, and bounce rates.

## Objectives
- Analyze total website visitors.
- Calculate total page views.
- Identify the most popular traffic source.
- Analyze visitors by device.
- Study daily website traffic.
- Analyze average bounce rate.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Dataset Information
The dataset contains 10 records and 6 columns.

| Column | Description |
|---|---|
| Date | Website visit date |
| Visitors | Number of visitors |
| PageViews | Total page views |
| TrafficSource | Source of website traffic |
| Device | Device used by visitors |
| BounceRate | Website bounce rate |

## Analysis Performed
1. Data inspection and cleaning.
2. Missing value detection.
3. Duplicate record detection.
4. Exploratory Data Analysis (EDA).
5. Traffic source analysis.
6. Device-wise visitor analysis.
7. Data visualization.

## Key Findings
- Total Visitors: 2,150
- Total Page Views: 5,200
- Average Visitors: 215
- Average Bounce Rate: 38.8%
- Leading Traffic Source: Google
- Most Used Device: Desktop
- Highest Visitors: 350
- Lowest Visitors: 100
